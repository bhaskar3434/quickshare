Settings

Phones pause websites when the screen locks, which pauses transfers. The screen is always kept on during a transfer.

If the same photo or file is sent again by mistake, it isn't downloaded twice. The sender can tap “Send anyway”. In a chosen save folder, a changed file with the same name replaces the old one.

Advanced

If two devices on different networks (for example, both on mobile data) can't connect, add a TURN relay on both devices. Relayed files stay end-to-end encrypted — the relay can't read them. The 🩺 check tells you if you need this.
